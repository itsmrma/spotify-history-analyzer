# Feature tour

[Watch the 24-second video](music-history-tour.mp4) · [Looping GIF](music-history-tour.gif)

The tour shows the actual app: importing files, listening statistics, monthly and
weekly charts, the annual calendar and daily songs, artist search, scrobbler
sources, artist rankings and CSV export. All listening records and artist names
shown are synthetic. No personal listening export or live scrobbler account was
used.

The MP4 is 1920 × 1080 at 30 fps. The silent GIF is 1280 × 720 at 12 fps, loops
continuously and uses an optimized shared palette. Clicking the README preview
opens the MP4.

Created with [Brag](https://github.com/latent-spaces/brag) and
[HyperFrames](https://github.com/heygen-com/hyperframes), using real browser
captures of this project.
